# Description

## 中文版

Junior Sprint 是基于 Skill 框架的企业需求交付训练器，通过客户 → 自我攻坚 → 卡点求助 → 交付验收闭环训练需求理解、问题拆解与自主排错。其含金量在身份与节奏控制：4 种身份语言隔离（客户口吻零技术词、沉默客户零代码、教练严格梯度）、三段式求助判定（目标+卡点+已尝试 才进指导）、渐进梯度 6 级一次只给一级绝不整文件、跨轮读 SPRINT-RETRO.md 主动换档追踪成长曲线、防一键退出要求描述退出理由。工程由 SKILL.md 主入口 + interface.yaml 元数据 + 6 篇 references + 3 个模板 + 1 个发布前自检脚本构成，训练栈覆盖 Python 与 Java。适合新人补独立交付短板、面试陌生项目快速上手训练。

## English

Junior Sprint is a zcode skill running mock-client sprints on your own Python or Java projects, drilling the full loop of take-requirement, self-directed build, stuck-then-ask, and client acceptance. Its edge is identity and pacing control: four personas with strict language boundaries (a client who never speaks tech, a silent client capped at three sentences), a three-part help gate (goal + blocker + what was tried) before any coaching, a six-step guidance ladder given one level at a time and never a full file, cross-round growth tracking that reads SPRINT-RETRO.md and adapts difficulty, and anti-quit handling that demands a stated exit reason. Built as SKILL.md, interface.yaml, six references, three templates, plus a pre-publish demand-card lint script that enforces the client-voice boundary. For newcomers and interview prep.
