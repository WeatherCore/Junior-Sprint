# Sprint 状态文件 · 跨轮持久化模板

> 保存路径：`<项目根目录>/.junior-sprint/state.md`（AI 直接写入；建议学习者把 `.junior-sprint/` 加入 .gitignore）
> 用途：长 Sprint 跨多轮对话时防止失忆。AI 在阶段切换或重要节点后主动更新此文件。
> 与 `SPRINT-RETRO.md` 的关系：state 记"过程"，retro 记"成长"。

---

## 基本信息

- **sprint_id**：S-{YYYYMMDD}-{序号}，如 `S-20260820-01`
- **project**：{项目名 / 技术栈}
- **difficulty**：L{1/2/3}
- **estimate**：{学习者交付估时（阶段 1 收集，如"半天"），复盘时对比实际}
- **session_count**：本轮 Sprint 已进行的对话次数：{N}
- **started_at**：{ISO 8601 时间}
- **last_updated**：{ISO 8601 时间}

## 当前状态

- **current_stage**：{0/1/2/3/4}
- **stage_name**：{Scout / Partner / 学习者攻坚 / 卡点指导 / 验收复盘}
- **current_identity**：{侦察员 / 客户 / 沉默客户 / 教练 / 严格客户→教练}

## 需求卡快照

- **demand_title**：{一句话需求}
- **designed_fuzzy_points**：{本轮刻意留下的 1-2 个模糊点，复盘时核对学习者是否主动澄清}
- **background**：{业务背景一句话}
- **wants**：
  - {业务行为 1}
  - {业务行为 2}
- **acceptance_criteria**：
  - {验收点 1}
  - {验收点 2}
  - {验收点 3}

## 已交付步骤

> 按时间顺序记录学习者已完成的实质步骤（不是 AI 给的步骤）

1. {步骤 1，如"在 order_service 加了 create_order 方法骨架"}
2. {步骤 2}
3. ...

## 卡点记录

> 每个卡点：卡在哪 + 渐进梯度走到第几级 + 是否解决

- 卡点 1：{描述} · 梯度 {1-6} · {已解决 / 进行中}
- 卡点 2：{描述} · 梯度 {1-6} · {已解决 / 进行中}

## 上轮复盘引用

> 本轮启动时从 `SPRINT-RETRO.md` 读出的上轮关键信息，用于做成长对比

- **last_sprint_id**：{上轮 ID}
- **last_scores**：需求理解 {1-5} / 拆解 {1-5} / 排错 {1-5} / 工程习惯 {1-5} / 沟通 {1-5}
- **last_highlights**：{上轮亮点 1-3 条}
- **last_improvements**：{上轮改进点 1-3 条}
- **本轮重点训练**：{基于上轮改进点选定的本轮训练重点}

## 防失忆最小集

> 如果学习者不想维护完整状态文件，AI 在对话结尾总结这四条并提示保存即可

1. **当前阶段**：{阶段 0-4 + 名称}
2. **难度档**：L{1/2/3}
3. **已交付**：{一句话}
4. **当前卡点**：{一句话或"无"}
